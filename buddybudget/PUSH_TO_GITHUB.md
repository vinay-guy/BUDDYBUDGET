# GitHub Push Helper Script
# Replace YOUR_USERNAME with your actual GitHub username before running!

# Step 1: Add remote repository
# git remote add origin https://github.com/YOUR_USERNAME/buddybudget.git

# Step 2: Push to GitHub
# git push -u origin main

# After successful push, your repository will be available at:
# https://github.com/YOUR_USERNAME/buddybudget

# To verify remote was added:
# git remote -v

# If you need to change the remote URL later:
# git remote set-url origin https://github.com/YOUR_USERNAME/buddybudget.git
